# 🎯 Animated Skills Progress Bars

## 📌 About the Project
This project displays technical skills using animated progress bars. The bars fill smoothly to their target percentages when the skills section appears on the screen.

## ✨ Features
- Five skill bars with labels and percentages.
- Smooth CSS animations.
- Animation on scroll using JavaScript.
- Responsive design for mobile and desktop.
- Simple and user-friendly interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- IntersectionObserver API

## 📂 Project Structure
```text
Animated-Skills-Progress/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 📊 Skills Displayed
- HTML5 – 90%
- CSS3 – 80%
- JavaScript – 75%
- Python – 70%
- Java – 65%

## 🚀 How to Run
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Scroll to the skills section to see the animations.

## 🎓 Learning Objectives
- Learn CSS transitions and animations.
- Practise JavaScript DOM manipulation.
- Understand scroll detection with IntersectionObserver.
- Create a responsive webpage.
